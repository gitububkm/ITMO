# Формулы для вставки в Microsoft Word

Есть **два удобных способа**. Рекомендую способ A.

---

## Способ A (самый простой) — копировать готовое уравнение

1. Откройте файл **`ЛР2_Формулы_ГОТОВЫЕ_для_копирования_в_Word.docx`**.
2. Кликните по нужной формуле (она уже является уравнением Word).
3. `Ctrl+C` → в своём отчёте `Ctrl+V`.
4. Формула вставится «как формула», её можно редактировать.

Так переносить быстрее всего, Word сам всё распознаёт.

---

## Способ B — вставить код через редактор уравнений Word

1. В Word поставьте курсор туда, где нужна формула.
2. Нажмите **Alt+=** (или лента: **Вставка → Уравнение**).
3. На вкладке **«Работа с уравнениями» / Equation** найдите режим ввода:
   - **LaTeX** — вставляйте строки из раздела «Код LaTeX» ниже;
   - либо оставьте обычный режим и вставляйте строки из раздела «UnicodeMath».
4. После вставки кода нажмите **Convert / Преобразовать → Current - Professional** (или Enter/пробел — в зависимости от версии Word).

Подходит для Word Microsoft 365 / Word 2019 / 2021. В очень старых Word режима LaTeX может не быть — тогда используйте способ A.

---

## Код LaTeX (для режима LaTeX в уравнении Word)

Копируйте **только содержимое** строки кода (без кавычек).

### Базовые формулы

```
Th=\frac{ER}{100}\cdot\frac{P(V)}{100}
```

```
CTh=1-\prod_{i}(1-Th_{i})
```

```
CThR=1-\prod_{j}(1-CTh_{j})
```

```
R=D\cdot CThR
```

```
R_{\%}=CThR\cdot 100\%
```

```
CR=R
```

### Расчёты Th

```
Th_{1.1}=0{,}60\cdot 0{,}50=0{,}30
```

```
Th_{1.2}=0{,}60\cdot 0{,}20=0{,}12
```

```
Th_{2.1}=0{,}40\cdot 0{,}60=0{,}24
```

```
Th_{2.2}=0{,}40\cdot 0{,}10=0{,}04
```

```
Th_{3.1}=0{,}80\cdot 0{,}10=0{,}08
```

```
Th_{3.2}=0{,}80\cdot 0{,}80=0{,}64
```

> Если Word ругается на `{,}` — замените запятую на точку: `0.60`, `0.50` и т.д.

Вариант с точкой (часто надёжнее):

```
Th_{1.1}=0.60\cdot 0.50=0.30
```

```
Th_{1.2}=0.60\cdot 0.20=0.12
```

```
Th_{2.1}=0.40\cdot 0.60=0.24
```

```
Th_{2.2}=0.40\cdot 0.10=0.04
```

```
Th_{3.1}=0.80\cdot 0.10=0.08
```

```
Th_{3.2}=0.80\cdot 0.80=0.64
```

### Расчёты CTh

```
CTh_{1}=1-(1-0.30)(1-0.12)=1-0.70\cdot 0.88=1-0.616=0.384
```

```
CTh_{2}=1-(1-0.24)(1-0.04)=1-0.76\cdot 0.96=1-0.7296=0.2704
```

```
CTh_{3}=1-(1-0.08)(1-0.64)=1-0.92\cdot 0.36=1-0.3312=0.6688
```

### CThR и риск

```
CThR=1-(1-0.3840)(1-0.2704)(1-0.6688)=0.851148\approx 0.851
```

```
R=D\cdot CThR=100\cdot 0.851148\approx 85.11
```

```
R_{\%}=85.11\%
```

```
CR=R\approx 85.11
```

## UnicodeMath (обычный режим уравнения Word, без LaTeX)

Вставляйте после Alt+=, затем пробел/Enter для «сборки» формулы.

```
Th=(ER/100)·(P(V)/100)
```

```
CTh=1-∏_i(1-Th_i)
```

```
CThR=1-∏_j(1-CTh_j)
```

```
R=D·CThR
```

```
R_%=CThR·100%
```

```
CR=R
```

```
Th_1.1=0.60·0.50=0.30
```

```
Th_1.2=0.60·0.20=0.12
```

```
Th_2.1=0.40·0.60=0.24
```

```
Th_2.2=0.40·0.10=0.04
```

```
Th_3.1=0.80·0.10=0.08
```

```
Th_3.2=0.80·0.80=0.64
```

```
CTh_1=1-(1-0.30)(1-0.12)=0.384
```

```
CTh_2=1-(1-0.24)(1-0.04)=0.2704
```

```
CTh_3=1-(1-0.08)(1-0.64)=0.6688
```

```
CThR=1-(1-0.384)(1-0.2704)(1-0.6688)≈0.851
```

```
R=100·0.851≈85.11
```

## Если формула не преобразовалась

1. Убедитесь, что курсор внутри поля уравнения (серая рамка), а не в обычном тексте.
2. В Word 365: вкладка Equation → **LaTeX** → вставить код → **Convert**.
3. Не копируйте тройные кавычки \`\`\` из markdown — только саму строку формулы.
4. Запасной путь: способ A (копирование из `.docx`).
